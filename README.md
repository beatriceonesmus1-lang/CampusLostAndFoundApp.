# Campus Lost And Found App

An app to help students in campus report lost items and find found items easily.

## Problem
Students lose IDs, phones, keys, books every day and don't know where to look.

## Features
- Report a lost item
- Report a found item
- Search for lost items
- View all items
- Contact the owner

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the app
2. Click "Report Lost" or "Report Found"
3. Fill the form with item name, place, date
4. Submit
